# Updating research images

1. Upload a JPG, PNG, WebP, or SVG to this folder using Add file > Upload files, then commit to main.
2. Edit research.html and replace the corresponding image src with your new filename (including its extension). Update alt to describe the figure.
3. Commit the HTML change. GitHub Pages publishes automatically.

| Theme | Current placeholder |
| --- | --- |
| UAS inspection | images/uas-inspection.svg |
| Assistive navigation | images/assistive-navigation.svg |
| Soil moisture | images/soil-moisture.svg |
| Materials and structures | images/materials-structures.svg |

Example: src="images/uas-inspection.jpg" alt="Drone flight path around a bridge model"

Recommended: landscape images around 1200 × 750 pixels, under 1 MB when practical. Images are contained without cropping. Do not rename a JPG to .svg: update the src extension instead. To replace an existing image, upload the same filename to this folder. Refresh the website after deployment; if needed use Ctrl+F5.
